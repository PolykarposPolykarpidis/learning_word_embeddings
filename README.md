# learning_word_embeddings


Τα embeddings του Skip-Gram with Negative Sampling αναπαριστούν τη σχεσιακή θέση μιας λέξης σε ένα σύστημα που ανασυντίθεται στατιστικά από ένα corpus. Επειδή προκύπτουν μόνο από σύγκριση λέξεων μεταξύ τους, χωρίς σύνδεση με έννοια ή αναφερόμενο, βρίσκονται πλησιέστερα στη σωσσυριανή "αξία" παρά στη "σημασία". Η εγγύτητα στον χώρο δεν είναι όμως η ίδια η αξία, αλλά ένδειξη ότι οι λέξεις μοιράζονται την ίδια περιοχή. Η αξία προκύπτει από τις διαφορές μέσα σε αυτήν.
